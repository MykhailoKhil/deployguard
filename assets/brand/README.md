# DeployGuard brand assets

- `mark.svg` — standalone mark on a transparent background.
- `wordmark-dark.svg` — transparent logo for dark backgrounds.
- `wordmark-light.svg` — transparent logo for light backgrounds.
- `social-banner.svg` — 1200 × 630 banner for social sharing or presentations.

The mark combines a shield with a change path and checkpoint. The palette follows
the application: forest green `#1f5a46`, mint `#9ad9b2`, and dark `#101613`.
SVG files are editable and scale without losing quality. Wordmarks use system
font fallbacks, so their appearance can vary slightly across platforms.
